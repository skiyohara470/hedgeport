# HedgePort

HedgePortは、SFTP・Amazon S3・ローカルファイルを一つの画面で操作できるデスクトップアプリです。

## 主な機能

- SFTPサーバーとAmazon S3のファイルを操作
- リモートとローカルのファイルを並べて表示
- ファイルやフォルダーのアップロード、ダウンロード、コピー、削除、名前変更
- フォルダーを含む一括ダウンロード
- ファイルのプレビューとテキスト編集
- 日本語／英語表示、ライト／ダークテーマ

## 入手とインストール

GitHubからソースコードをダウンロードしただけでは、アプリはまだインストールされていません。現在、完成したアプリやインストーラーは配布していないため、次の手順で `.app` を作成してからインストールします。この手順はmacOSのApple Silicon搭載機（M1以降）向けです。

1. [Node.js 22.12.0以上](https://nodejs.org/en/download)をインストールします。npmも一緒にインストールされます。
2. 「ターミナル」を開き、次のコマンドを順番に実行してソースコードを取得し、アプリを作成します。

   ```bash
   git clone https://github.com/skiyohara470/hedgeport.git
   cd hedgeport
   node -v
   npm -v
   npm ci
   npm run package:mac
   open release/mac-arm64
   ```

   `node -v` が `v22.12.0` 以上であることを確認してください。最後のコマンドでFinderにアプリの作成先が表示されます。

   GitHubの **Code → Download ZIP** から取得する場合は、ZIPを展開します。ターミナルで `cd ` と入力し、展開した `hedgeport` フォルダをFinderからターミナルへドラッグしてReturnキーを押します。そのフォルダで次を実行してください。

   ```bash
   node -v
   npm -v
   npm ci
   npm run package:mac
   open release/mac-arm64
   ```

3. Finderに表示された `hedgeport.app` を「アプリケーション」フォルダへドラッグします。これでインストール完了です。

初回起動時にmacOSから確認された場合は、Finderの「アプリケーション」フォルダでHedgePortをControlキーを押しながらクリックし、「開く」を選んでください。開発用の起動やその他のコマンドは[開発手順](docs/development.md)を参照してください。

## 起動方法

インストール後は、Finderの「アプリケーション」フォルダからHedgePortをダブルクリックするか、Launchpadで「HedgePort」を選んで起動します。ターミナルや `npm run dev` は、通常の利用時には必要ありません。

## 接続設定

初回起動後、接続先を登録します。

- **SFTP**：接続名、ホスト、ポート、ユーザー名、開始フォルダー、パスワード
- **Amazon S3**：接続名、リージョン、Access Key ID、Secret Access Key（必要に応じてSession Token）

S3は接続後にアクセス可能なバケットが一覧表示されます。

## データとプライバシー

接続情報とアプリの設定は、このMacのアプリ用データ領域に保存されます。パスワードやAWS認証情報はmacOSの暗号化機能を使って保護します。アプリのデータは別の端末へ自動同期されません。

## 現在の制約

- 配布用インストーラー、コード署名、自動更新には対応していません。
- 大容量ファイルの転送では、ファイル全体をメモリに読み込む場合があります。
- 転送の進捗表示、キャンセル、再試行、再開には対応していません。
- プレビューできるファイルは最大20 MiB、アプリ内で編集できるファイルは最大1 MiBです。
